# Customer Churn Analysis

## Project Overview
This project analyses customer data to understand why customers discontinue their subscriptions.

## Objectives
- Calculate customer churn rate.
- Calculate Customer Lifetime Value (CLV).
- Identify Monthly Recurring Revenue (MRR) loss.
- Analyse churn by contract type.
- Analyse churn by customer tenure.
- Analyse churn by payment method.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- GitHub

## Business Recommendations
1. Improve customer satisfaction.
2. Provide loyalty rewards.
3. Identify customers at risk of leaving.
4. Encourage long-term contracts.
5. Improve payment support.
